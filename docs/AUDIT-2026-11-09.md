# Don Eduardo runtime audit · 2026-11-09

Base `453c2fa`, AML `8f577e8`. The audit followed observations through
the ledger, action traces, routing, JANUS, saved worlds, HTTP, MCP and the
browser. Source fixtures used synthetic earthquakes, device fixes and
camera frames. Native tests launched the pinned AML runtime and reopened
its on-disk memory in a fresh process.

## Findings and regression cases

| Where | Reproduction on the merged code | Behavior after the fix |
| --- | --- | --- |
| Background intake | Change a submitted signal before the receive queue drains. The receipt picks up the later value and source. | Intake snapshots the frame on submission, including browser coordinate getters. |
| Don's attention | Mark a trace as executed with a failed result. A USGS subject can then become Don's focus. A host signal could also label itself as an action. | Attention requires a successful supported read. Subject evidence and cutoff are checked. Only an action frame can submit an action source. |
| Device restoration | Put 257 three-receipt fixes or more than 1.5 MB of camera data in an otherwise admissible combined journal. It opens under the larger world budget. | Restart and selection enforce each device's own record and byte limits. |
| USGS history and capacity | Alter an old magnitude's source, then submit an empty poll. Separately, ingest 96 events with heavily escaped place names. Both calls succeed, even though the latter result cannot be saved. | Ingestion checks every prior USGS version and encodes the full candidate within the byte limit before returning it. Other instruments can still share the journal. |
| USGS decoding | Inject byte `ff` into a source string over HTTP or in an imported revision. The decoder can substitute U+FFFD and attach the changed text to the source. | Both byte inputs require valid UTF-8. The last accepted journal survives rejection. |
| Original-world inspector | Open a generic saved world with only a camera width receipt. Optional JPEG reconstruction throws before the raw evidence is displayed. | The inspector reports the preview error and still reproduces the tool result and shows its receipts. |
| Device time display | A valid integer device clock outside the JavaScript Date range throws during formatting. | Camera and location views show the exact Unix milliseconds at that boundary. |
| C/AML differential test | Drop `calls[0]` or change the reasoning evidence while keeping winner and scores. The old gate accepts the output. | The gate compares the complete selected calls and evidence and retains the numerical tolerance of `1e-4`. |

## Cross-checks

* On 16 generated histories, an independent reference retired predecessors
  in receipt order, then evaluated each surviving claim at the world instant.
  Three stored prefixes and four cutoff pairs per history gave 192 comparisons.
  The saved and current verdicts, final premise identity comparison, receipt
  IDs, evidence roles and intervening change counts agreed.
* Seven Unix instants gave 49 ordered pairs across years 1 through 9999,
  March 1900, leap year 2000 and the millisecond before the Unix epoch.
  Checked civil dates against UTC, signed durations against integer
  subtraction, and the portable JANUS result against the native AML bridge.
* All 83 checked-in routing cases passed the stricter C/AML comparison.
  An additional 66 local variants exercised multilingual suffixes, punctuation,
  numeric-looking strings, negation and compound requests. The C oracle also
  ran both sets with GCC AddressSanitizer and UndefinedBehaviorSanitizer.
* Native integration covered concurrent writers, torn and missing files, byte
  exhaustion, old action formats, restart, HTTP and MCP replay. The browser
  gate exercises rejected imports and camera-preview failure alongside the
  existing permission, capture, replay and IndexedDB tests.

## Reproduce the maintained gates

Debian 13 x86_64, Node 24.22.1, GCC 14.2.0. Initialize the pinned submodule
before building. The measured runs passed 111 core and 27 integration tests,
83 checked-in routing comparisons and all four JavaScript and two AML examples.

```sh
git submodule update --init
node scripts/build-router.mjs
node scripts/build-aml.mjs
make -C deps/aml calendar-bridge
node --test tests/*.test.js
node --test tests/*.integration.mjs
node scripts/wolfe-diff.mjs
node scripts/browser-check.mjs
```

Local Chromium stopped before page load because its process singleton socket
was denied. GitHub Actions runs the same browser command on Ubuntu. Physical
phone permission flows, capture quality and storage after closing the browser
remain field measurements.
